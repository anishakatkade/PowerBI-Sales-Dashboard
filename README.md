
# 📊 PowerBI Sales Dashboard

## 🎯 Project Overview
Interactive Sales Dashboard built in Power BI analyzing 
500+ sales transactions across products, regions and salespersons.

## 📌 Key Features
- Revenue & Profit KPI Cards (₹63M Revenue, 37% Margin)
- Monthly Revenue Trend Analysis
- Regional Sales Breakdown (4 Regions)
- Top Salesperson Performance
- Product Category Comparison
- Interactive Slicers for dynamic filtering

## 🛠️ Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Microsoft Excel
- GitHub

## 📊 Dashboard Pages
- Page 1: Sales Overview
- Page 2: Sales Performance
- Page 3: Regional Analysis

## 📈 Key Insights
- Laptop is top selling product (₹27M+ Revenue)
- West Region leads with 27.81% market share
- Q1 highest revenue quarter
- Anjali Singh top performing salesperson
